# Training studio entry paths

`/new` opens in Beginner mode. Advanced mode exposes the Ivme recipe, Hugging Face imports, training hyperparameters and scale calculator. Checkpoint forks open in Advanced mode. Switching paths preserves the current draft and never launches a run.

Connect my agent is a first-class path above the wizard. It provides copyable instructions and links to Goals for the current workspace or agent registration for an independent workspace. Goal-engine credentials only authorize that protocol; independent registration does not grant access to the human account.

The dataset recipe is an unboxed section inside the workspace panel, with one divider rather than nested rounded cards. Entry cards stack on small screens.
